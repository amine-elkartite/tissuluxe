# FAQ

## What is TissuLuxe?

TissuLuxe is a textile e-commerce platform designed to showcase and manage fabric products in a professional online store.

---

## Who is the project for?

The project is designed for textile shops, small businesses, customers, and developers who want to build or improve a fabric-focused e-commerce website.

---

## What are the main features?

The main features include a storefront, product catalog, product details, categories, admin panel, backend API support, and database integration.

---

## Does TissuLuxe include an admin panel?

Yes. The project includes or is designed to include an admin panel for managing products, categories, orders, customers, and store settings.

---

## Can the project support online orders?

Yes. The project can be extended to support cart, checkout, payments, and delivery tracking.

---

## Is sensitive information included in the documentation?

No. Public documentation should not include passwords, API keys, database credentials, tokens, or private configuration details.

---

## Can the Wiki be updated later?

Yes. The Wiki should be updated as the project evolves and new features are added.
